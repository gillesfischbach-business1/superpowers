# Reference material

Photographs and maps that the town's look is matched against. They are **cited here, not
redistributed**: the files belong to their publishers, so only the links are kept.

| Subject | Source | What it settled |
| --- | --- | --- |
| Rue de la Gare / shared space, Dudelange centre | paperjam.lu, “Dudelange vue depuis ses chantiers” — <https://paperjam.lu/article/dudelange-vue-depuis-ses-chant> | 3–4 storey plaster town houses built hard on the pavement, slate roofs, shopfronts and awnings at street level, pale paving. |
| Cité Italienne / “le village au sein de la ville” | paperjam.lu, “À Dudelange, un quartier historique” — <https://paperjam.lu/article/a-dudelange-quartier-historiqu> | 2-storey terraced cottages, narrow lanes, saturated pastel plaster (turquoise, coral, ochre, lilac), white frames, small front steps. |
| Street network of the commune | OpenStreetMap-derived street map (hebstreits “Dudelange city map”) — <https://hebstreits.com/> | The real grain: a linear valley town with a compact centre, a separate northern hamlet (Burange), an eastern arm (Cité Italienne) and the works to the south. No orthogonal grid anywhere. |

The OpenStreetMap source of truth for the streets themselves is `public/js/core/town-data.js`
(25 named roads, 25 traced points per road) — the map above was used to check that the generated
fabric reads like the real commune, not as a data source.
